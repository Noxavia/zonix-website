# Zonix website

Official Noxavia Games website preparation for Zonix, a landscape territory-capture puzzle with 250 levels, 50 Challenges and 50 photographs.

The reviewed static website supports thirteen languages. Zonix is coming soon; no public game download or public release is announced here. Gameplay requires internet. Progress is saved locally; there are no player accounts, in-app purchases or subscriptions.

Only intended public website assets are included in public_site.zip. The GitHub Pages workflow verifies the reviewed ZIP hash before deploying it. Game source, APKs, player data, signing material and substantive legal review drafts are excluded. Public policy/rights pages are status placeholders and are not legally approved notices.

Public support: noxaviagames@gmail.com

To update the website, rebuild and validate the public static package locally, then update its reviewed ZIP and corresponding workflow hash. Publish release notes only after an actual public game release.
